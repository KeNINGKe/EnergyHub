# 精选业务价值评分标准（阶段 C-01）

> 供 `scripts/lib/selection-score.mjs` 构建评分提示词。评分问题：**假设每天只能
> 给读者看 12 条消息，这条新闻值不值得占一个位置？** 与相关性判定（这条是否
> 属于能源/电力领域）是两个不同的问题——相关、真实、写得不错的消息也可能
> 没有信息增量。
>
> 读者画像：跟踪储能 / PCS / SST / AIDC 供电行业的从业者，关心供需、格局、
> 项目落地与政策变化。权重初值见 `data/editorial-policy.json`（校准前不是
> 既定有效权重）。

## 四个维度

### 1. 业务关联（0–30）

与读者业务的直接相关程度：

- **26–30**：直接命中核心方向——SST/PCS/EMS 器件与系统、AIDC 供电架构
  （800VDC/HVDC/母线）、储能系统与项目、重点公司（见 enums.priorityCompanies）
  的实质性动态。
- **13–25**：外围但有信号价值——电网/输配电、光伏风电、核电 SMR、燃气备用
  电源、液冷/UPS/PUE、绿电 PPA、电力市场政策对上述核心方向有传导影响。
- **1–12**：仅背景相关——宏观能源、泛半导体、与供电/储能无实质关联的科技新闻。
- **0**：无关（理论上进不了候选，防御性兜底）。

### 2. 事实增量（0–25）

相对「上周已知」的新信息量：

- **21–25**：新披露的具体事实——新数字（容量/金额/产能/效率）、新时间点
  （投运/交付/认证）、新当事方（首次进入某市场/某供应链）。
- **11–20**：已知事件的新进展——进入下一阶段（签约→开工→投产）、补充细节。
- **1–10**：复述、预告、观点/预测（无论断多大胆，无新事实就是低分）。
- **0**：纯转述且无增量（同事件第 N 篇重复报道）。

### 3. 项目/商业/政策影响（0–25）

对供需或格局的潜在影响：

- **21–25**：改变格局——头部厂商大额订单/扩产/退出、改变成本曲线的技术
  （如 SST 规模商用、固态电池量产）、影响北美/中国/中东重点市场的国家级政策。
- **11–20**：影响单个环节——中型项目、区域性政策、供应链单点变化。
- **1–10**：影响有限或方向不明。
- **0**：无实质影响（招聘、展会营销、股价日常波动、消费级产品评测）。

### 4. 证据充分度（0–20）

判定以上三维度所依据材料的扎实程度：

- **16–20**：一手来源（公告/监管文件/项目文件）或多家独立来源交叉印证。
- **8–15**：单家可信媒体报道，事实要素（主体/动作/数字）齐全。
- **1–7**：要素残缺（有数字无单位、有主体无动作）、仅引述传言。
- **0**：无法判定（软文、通稿模板、营销话术）。

## 输出协议

只输出一个 JSON 对象，不要任何解释或其他文字：

```json
{
  "scores": {
    "businessRelevance": 0,
    "factualIncrement": 0,
    "impact": 0,
    "evidence": 0
  },
  "total": 0,
  "keyFact": "一句话：这条报道最核心的新事实（无则空字符串）",
  "rationale": "一句话：打分理由，边缘案例必须写清为什么"
}
```

## 负向清单（符合任一基本 reject，影响面维度记 0）

1. 软文、通稿模板、展会营销、招聘、无具体用途与规模的融资套话。
2. 泛泛而谈的观点/预测文（无新事实支撑）。
3. 消费级产品评测、股价变动、与电力/储能/AIDC 供电无实质关联。
4. 同一事件的第 N 篇重复报道。

## 边界提醒

- 相关 ≠ 该精选；短期平淡但给出关键节点（认证、交付、投运）的值得高分。
- 数字、公司名、项目名只能依据输入材料，不得臆测；材料没有的事实增量记低分。
- 独立来源数（independentSourceCount）是证据维度的一部分，但不与来源数线性
  挂钩——一家权威一手来源胜过五家转载。
