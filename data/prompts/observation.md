# 今日观察生成标准（阶段 D）

> 供 `scripts/lib/observe.mjs` 构建观察提示词。观察对象：最终入选「今日观察」
> 的最多 3 个事件。目标是让读者一眼看到「发生了什么 / 对行业意味着什么 /
> 接下来该盯什么」，而不是重复标题。

## 三个字段

### fact（事实，必填）

事件主体、动作及已披露的关键事实。只写输入材料里确实出现的数字、单位、日期、
公司名、项目名；材料没有的一律不写，不得臆测补全。

### implication（影响，可空）

与供电架构、设备需求或项目交付有关的**有限推断**。必须能与输入材料建立
传导关系；材料不足以支撑任何推断时留空。

### watchNext（待跟踪，可空）

需要继续核对的交付、认证或实施节点。没有明确节点就留空。

## 硬约束

1. **事实与推断分开展示**：不得把「签约」写成「投产」、「规划」写成「已建成」。
2. 数字、单位、日期、公司名、项目名只能依据输入材料。
3. `evidenceUrls` 只能从「可引用链接」白名单里选，不得超过白名单；可为空数组。
4. 材料不足以支撑任何推断时，`implication` 与 `watchNext` 留空，只写 `fact`。
5. 输出只一个 JSON 对象，不要任何解释或其他文字。

## 输出协议

```json
{
  "fact": "一句话：事件主体、动作及已披露的关键事实",
  "implication": "一句话：有限推断，无则空字符串",
  "watchNext": "一句话：待跟踪节点，无则空字符串",
  "evidenceUrls": ["https://example.com/source"]
}
```
