========================================
Energy Info Hub — 能源/储能/AIDC 信息聚合导航站
========================================
（更新日期：2026-09-28）

【项目简介】
一个纯静态、零服务器成本的信息聚合导航站，聚焦能源、储能、电力电子与
AI 数据中心（AIDC）交叉领域。

核心能力：
1. 综合导航页 —— 按 13 个分类展示 230+ 国内外信息源，点击直达；
2. 自动日报 —— GitHub Actions 定时抓取各源 RSS/页面，生成 JSON 静态数据，
   北京时间每天 05:00 / 12:00 各构建一次；
3. 热点榜 + 精选 —— 构建端自动产出热点榜（规模分/软曝光惩罚/跨日曝光记忆），
   精选 12 条；每天 08:00 推送钉钉群；
4. 深研区 —— 手动/AI 辅助填充的精选长文。

【技术栈】
- 前端：原生 HTML + CSS + JS，无框架无构建
- 数据：data/sources.json 驱动导航；feeds/*.json 由脚本生成
- 自动化：scripts/ 管线 + GitHub Actions cron
- 托管：GitHub Pages（大陆主入口）+ Cloudflare Workers 备份
- 智能：接入 TypeSafe/Jev 做捞回校准、主题仲裁与语义合并
